How I Used CSS in this Portfolio

This multipage portfolio heavily utilizes the Bootstrap 5 framework for its structural grid, responsive navigation bar, and utility classes (like spacing, text alignment, and shadows).

Custom CSS Implementation

To fulfill the custom CSS requirement, I created a separate style.css file that loads after the Bootstrap CDN to override and extend default styles. Specifically, I implemented:

  • Brand Styling: I created a .custom-brand-color class to override the default navbar text color, applying a deep maroon hex code to give it an academic feel, increasing font weight, and adding letter spacing.
  • Hover Transitions: I added a .custom-img-hover class to the grid thumbnails and detail gallery images. Using CSS transition and transform: translateY() properties, the images slightly elevate and increase their drop shadow when a user hovers over them, creating a modern, interactive feel.
  • Uniform Sizing: I implemented a .fixed-img class using object-fit: fill to ensure all thumbnails and gallery pictures stretch to perfectly fill a uniform height, guaranteeing the layout remains mathematically consistent regardless of the original image dimensions.
